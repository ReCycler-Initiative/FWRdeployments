# FRWDeployments concept and MVP plan

The maintained English concept is [Concept and MVP plan](../konsepti_ja_mvp_suunnitelma.md).
This context entry links to the single authoritative document to avoid divergent
copies of the product definition.

The current product supports multiple projects, multiple individually planned
workshops, contextual document/GitHub imports, solution comparison and a live
review canvas. Delivery can be refined Copilot/Claude prompts, an implementation
plan or an explicitly requested agent chain. Implementation progress is tracked
separately, including work performed outside this application.

The interface supports Finnish and English. Project content language controls
new generated outputs; existing source material is preserved in its original
language. Automatic Notetaker meeting participation remains future work.

See the [README](../readme.md) for setup, API configuration and MVP limitations.
